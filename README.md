# # Mon petit agenda — BZH & Ch'ti

Un agenda personnel simple, à utiliser à son rythme, une a choisi après l'autre.

Ce dépôt contient le site de présentation de **Mon petit agenda**, ainsi que ses pages de confidentialité et ses conditions d'utilisation.

## Le logique

Mon petit agenda fonctionne sur un PC Windows et se connecte à Google Agenda et Google Tasks pour :

- Consulter les rendez-vous et les tâches.
- Créer des rendez-vous dans Google Agenda.
- Ajouter des tâches dans Google Tasks.

La connexion conservée sur le PC est protégée par Windows.

## Le site

Le site présente le logique et explique son utilisation des données Google. Il est destiné à être hébergé sur GitHub Pages.

**Le logique et les données personnelles de l'utilisateur ne sont pas publiées dans ce dépôt.**
